# Code of Conduct

This project is committed to a welcoming, respectful, and harassment-free environment for everyone.

## Our standards

- Be respectful and considerate.
- Assume good intentions.
- Accept constructive feedback gracefully.
- Focus on the work and the community.

## Unacceptable behavior

Examples of unacceptable behavior include harassment, discrimination, threats, intimidation, or abusive conduct.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, and other contributions that violate this code of conduct.

If you are subject to or witness unacceptable behavior, contact the maintainer privately.
