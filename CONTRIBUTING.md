# Contributing

Thanks for your interest in improving this project.

## Workflow

1. Fork the repository.
2. Create a feature branch.
3. Make focused, tested changes.
4. Run the project checks locally.
5. Open a pull request with a clear description.

## Quality bar

- Keep changes minimal and relevant.
- Preserve accessibility and responsive behavior.
- Update documentation when the public behavior changes.
- Ensure HTML and security-related metadata remain valid.

## Local validation

```bash
python -m unittest discover -s tests -v
```
